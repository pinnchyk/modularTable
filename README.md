# modularTable
Simple program that calculates the different operations tables for modular systems of a chosen modulus, and then saves it as an image on which each pixel represents each cell of the table. Starting from upper left pixel at (0,0), all the way til the bottom right pixel being (modulus - 1, modulus - 1). The colors of each pixel range from black to white, with the visible light spectrum in between; put in another words, if 0 is 0, and 1 is modulus minus one, then colors smoothly transition between these colors: black (0,0,0) for 0/7, red (255,0,0) for 1/7, yellow(255,255,0) for 2/7, green (0,255,0) for 3/7, cyan (0,255,255) for 4/7, blue (0,0,255) for 5/7, pink (255,0,255) for 6/7, white (255,255,255) for 7/7.
Aside from the sum and rest tables, other ones follow interesting patterns, which I will be investigating on my own further on. If you find any interesting links to the patterns that appear on the images, and/or have any explanations on why they do, do let me know.
In case the program doesn't work properly, open it through a terminal.
